# Blender Practice

This is my Blender Practice — a structured collection of all Blender exercises, experiments, project files, progress renders, and learning notes.

This repository documents not only the final results of each practice project, but also the process behind them: what I practiced, what went wrong, how I solved problems, and what I plan to improve.

## Purpose

I created this repository to:

* Build consistent Blender skills through practice
* Keep my Blender project files organized
* Document techniques, shortcuts, mistakes, and solutions
* Track my progress over time
* Create a transparent portfolio that shows both finished work and the learning process behind it

This is a learning repository, so some projects may be incomplete, experimental, or intentionally simple.

## Practice Project Format

Each practice folder is intended to contain:

* The primary `.blend` project file
* A project-specific README
* Progress screenshots or renders
* A final preview when the project is completed
* References and asset credits
* Notes about challenges, solutions, and lessons learned

## Learning Notes

Reusable information is stored in the `notes` folder/files.

Examples include:

* Frequently used keyboard shortcuts
* Modifier settings
* Material node setups
* Lighting techniques
* Render settings
* Common Blender problems and their solutions

## Project Statuses

Practice projects may use the following status labels:

* **Planned** — The exercise has been selected but not started
* **In Progress** — The project is actively being worked on
* **Complete** — The exercise, notes, and final preview are finished
* **Paused** — Work has temporarily stopped
* **Archived** — The project is being preserved but will not be continued

## Version-Control Workflow

Commits are used as meaningful progress checkpoints rather than waiting until a project is finished.

## Blender File Management

Blender project files are tracked using Git Large File Storage.

Blender backup files, autosaves, temporary renders, and simulation caches are excluded where possible.

## Third-Party Assets

Any textures, HDRIs, models, brushes, fonts, tutorials, reference images, or other resources that I did not create are documented.

Third-party resources are only included in the repository when their licenses permit redistribution.

Reference material that cannot legally be redistributed is credited but stored outside the repository.
